# Делегирование задач локальным моделям (MCP для Claude Code)

`delegate/server.py` — MCP-сервер (stdio, без зависимостей) с одним инструментом `local_llm`.
Claude Code отдаёт через него простые задачи моделям AI Manager и экономит свои токены.

## Откуда экономия

| Без делегирования | С `local_llm` |
|---|---|
| Агент читает файлы целиком → они в его контексте | Файлы читает сервер, в контекст агента идут только пути |
| Агент пишет результат (код, текст) своими токенами | Результат пишется сразу в `output_file`, агенту — одна строка-сводка |
| | Платим только за постановку задачи (~50–200 ток.) и короткий ответ |

Выгодно, когда **вход большой, а нужный выход маленький** (сводка лога, поиск по смыслу,
извлечение фактов) или **выход большой, но его не нужно читать** (докстринги, перевод,
бойлерплейт, тестовые данные). Невыгодно для задач, где результат всё равно придётся
проверять построчно, и для сложной логики — там дешевле сделать самому, чем переделывать.

## Параметры инструмента

| Поле | |
|---|---|
| `task` | Инструкция с форматом ответа |
| `files` | Абсолютные пути; `path:10-80` — диапазон строк |
| `output_file` | Записать результат в файл (без ```-обёрток); может совпадать с входным — перезапись. Если ответ обрезан по `max_tokens`, файл не пишется |
| `model` | `code` → qwen3-coder-30b (100k), `text` → qwen3.6-35b (RU), `reason` → gpt-oss-20b, или точное имя. По умолчанию — **уже активная** модель (без переключения GPU) |
| `compact` | Сжатие входа: `light` (по умолчанию — хвостовые пробелы, лишние пустые строки, повторы, строки длиннее 2000 симв.), `logs` (+ схлопывание строк, отличающихся только числами/временем), `none`. С `output_file` всегда `none` |
| `line_numbers` | Пронумеровать строки входа (для задач «где находится X») |
| `max_tokens` | Лимит ответа (100000; без `output_file`) |
| `timeout_sec` | Лимит выполнения одного запроса к модели (3600) |
| `max_return_chars` | Обрезка возвращаемого текста (4000) |

## Оптимизация контекста

- **Сжатие входа** (`compact`) — меньше токенов локальной модели при том же смысле;
  в сводке вызова видно `сжатие N → M симв.`. На логах `logs` сжимает в десятки раз.
- **Автонарезка (map-reduce)** — если вход не влезает в контекст модели, файлы режутся на части
  (по границам пустых строк, с диапазонами строк в заголовках), задача выполняется по каждой части,
  затем частичные ответы сливаются (при необходимости — в несколько кругов). Части без релевантного
  отвечают `NOTHING` и при слиянии отбрасываются. Предел — `DELEGATE_MAX_CHUNKS` частей (24).
- **Перезапись по частям** — с `output_file` и одним большим входным файлом каждая часть
  переписывается отдельно и склеивается по порядку. Годится для построчных правок (перевод,
  комментарии, докстринги), не для правок, связывающих разные места файла.
- **Калибровка оценки токенов** — символов на токен уточняется по фактическим `prompt_tokens`
  каждой модели, чтобы части заполняли контекст плотно, но без переполнения.

## Долгие задачи

Таймауты очереди AI Manager — `DELEGATE_TIMEOUT` (выполнение, 3600 с на запрос) и
`DELEGATE_WAIT_TIMEOUT` (ожидание в очереди, 3600 с); при нарезке лимит действует на каждую часть.
Пока модель работает, сервер каждые 15 с шлёт `notifications/progress` (если клиент передал
`progressToken`) — клиенты, сбрасывающие таймаут по прогрессу, не обрывают долгий вызов.
Для Claude Code таймаут инструмента MCP задаётся переменной `MCP_TOOL_TIMEOUT` (мс) при запуске `claude`.

Задачи идут через очередь AI Manager с проектом `claude-delegate` (видны в `GET /api/queue`).

## Подключение

```bat
claude mcp add -s user ai-manager-delegate -- D:\projects\AI_Manager\venv\Scripts\python.exe D:\projects\AI_Manager\delegate\server.py
```

Если `claude` нет в PATH (стоит только десктоп-приложение) — CLI лежит в
`%APPDATA%\Claude\claude-code\<версия>\<хэш>\claude.exe`.

Настройки (переменные окружения или `.env` AI Manager): `DELEGATE_AIM_URL`,
`DELEGATE_DEFAULT_MODEL`, `DELEGATE_CODE_MODEL`, `DELEGATE_TEXT_MODEL`, `DELEGATE_REASON_MODEL`,
`DELEGATE_TIMEOUT` (сек, 3600), `DELEGATE_WAIT_TIMEOUT` (сек, 3600), `DELEGATE_MAX_TOKENS` (100000),
`DELEGATE_MAX_CHUNKS` (24), `DELEGATE_LONG_LINE` (2000), `DELEGATE_PROJECT`. Пароль — `AIM_PASSWORD` из `.env`.

## Статистика

Каждый вызов пишется в `data/delegate_log.jsonl`. Оценка экономии:

```bat
venv\Scripts\python delegate\stats.py
```
